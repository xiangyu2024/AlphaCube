## 0. 一句话现状 + 你的任务

**现状**:4196 个健康因子 → 两层合成出一个信号 → 纯多头前 20% 等权/轻度 exp 加权 +
EMA 平滑,**测试段超额夏普 +1.92、超额年化 +15.1%、超额回撤 −10.6%、日换手 4.0%**
(基准=等权全市场,成本单边 15bp)。

**你的任务**:把这个"理想持仓"变成**可交易的持仓**,并在约束下做优化:
1. **每只股票只能买整百股**(一手=100 股);
2. **单一股票占总金额不超过一个阈值**(阈值自己扫,看回测怎么变);
3. 在这两个约束下,**最大化某个与预期收益相关的目标** —— 用户给的例子:
   把合成因子值做 MinMax 归一化再取 exp 得到每只股票的"期望收益代理",
   然后以**实际持仓金额占比**为权重求加权平均,最大化它。

即:`max  Σ_i w_i · exp(MinMax(signal_i))`,`s.t. w_i = (100·n_i·price_i)/总金额`,
`n_i` 为非负整数,`w_i ≤ cap`,`Σ w_i ≤ 1`。这是个带整数约束的组合优化,
每天解一次,然后回测。

## 4. 因子从哪来

17 轮 GP(gpu2~gpu17)+ 1 轮 RL(rl1)+ 冒烟(memtest),合计 **4196 个健康因子**。
挖掘的适应度从 gpu10 起是 `|rank IC| − 0.14 × 十分位多空书日换手`(之前是 `|IC|`)。
各轮之间用"结构封禁 + rank 相似度封禁"避免重复挖:到 gpu17 累计 64 条结构封禁、
9 个 ban-archive(1851 条 exemplar)。

**各轮因子的样本外质量**(测试段扣费净夏普中位,全部单因子):
gpu3 +0.93 / gpu11 +0.85 / gpu15 +0.61 / gpu12 +0.34 / gpu16 +0.29 / gpu14 +0.20 /
gpu17 −0.29 / gpu5 −0.11 / **老 |IC| 口径的 gpu7 −2.36、gpu9 −2.96、gpu8 −3.10**。
→ 换目标函数(加换手惩罚、改 rank IC)是这个项目最大的一次单项改进。

**RL(rl1)**:AlphaGen PPO,2000 回合 9.1 小时,产出 1465 个合法表达式、最终池 30 条。
单因子几乎全废(测试段净夏普中位 **−3.58**、换手中位 60.7%),但 30 条凑在一起
毛夏普 5.88、ICIR 0.515,平滑后多空 +3.97。**它的 alpha 大量在空头侧**(纯多头只有 +1.70)。

## 6. 已证实的结论 / 已证伪的假设

**证实**
1. **换目标函数最有效**:加换手惩罚 + 改 rank IC,把各轮因子的样本外中位从 −3 拉到 +0.6。
2. **正交化选因子有效**:+2.93 → +3.04/+3.10,而且能发现"抑制变量对"——某因子原始
   rank IC −0.011,配上同族伙伴后**测试段** rank IC +0.062(β 冻结在训练窗口,无前视)。
3. **两层合成最有效**:+3.10 → +3.98。族内摊平同一想法各写法的噪声,族间拟合权重。
4. **EMA 平滑把换手的边际成本从 −10.1 降到 −1.1 夏普/单位换手**(13 组回归,Pearson
   0.937)。**只要最后会平滑,适应度里 λ=0.14 就重了约 9 倍,应该是 0.016 量级。**
   **任何组合结果,不看平滑后的数字就不要排名。**
5. **优化训练目标越狠,样本外越差**:四阶段流程在三个训练段目标上全部第一(训练段
   扣费夏普 +3.12),测试段倒数第一(+1.74),训练排名与测试排名完全颠倒。
   **选择阶段要少优化,把自由度留给组合层。**
6. **有效宽度 = (Σλ)²/Σλ² = k²/Σλ²**(紧凑秩指纹的 |corr| 矩阵特征值)。两个质疑都
   验过且不成立:取绝对值+clip 与先对齐符号给出完全相同的数;采样量翻 4 倍 3.8 只变 3.9。
7. **天花板在宽度**:诚实挑法的最好单因子 +2.48,最好组合 +3.40,比值 1.31 →
   **等效独立数只有 1.7**。4196 个因子全来自同一个价量过程,这是根本限制。

**证伪**
1. **残差不能当因子交易**:两组独立实验,等权/IC 加权从 +2.00 掉到 −0.36(ICIR 0.25 → 0.078)。
   残差被剥掉的共同成分恰恰是可靠的那部分。**残差只用于挑因子。**
2. **Lasso 方向错了**:L1 让系数更集中(用户本意是分散),应该用 ridge;而 ridge 实测
   也比 OLS 差(+2.39 vs +3.04,有效宽度 4.8 vs 6.5)——"β 别集中"和"充分正交"
   是同一个旋钮的两端,**充分正交更值钱**。
3. **线性残差口径不对**:+2.13,远低于重排口径的 +3.10。我们的书交易的是**排序**。
4. **"更多因子 = 更好"不成立**:2775 → 4157 个因子,基线选法的组合从 +3.25 掉到 +2.93,
   因为选法不单调(有效宽度 4.7 → 3.8)。

## 7. 工程陷阱(全部今天踩过)

1. **anon 内存实际上限约 40 GB,不是 90 GiB**。同时拿住 500 个面板(40 GB)时进程
   **无声死亡**:没有 traceback,`memory.events oom_kill` 仍是 0,父 shell 活着。
   gpu14 当初也是这个特征。**几百个面板的活一律两遍扫描**(`combine_many.py` 是模板)。
2. **写出去的面板会把立方体的 page cache 挤掉**:批次耗时从 134 秒涨到 1700 秒。
   `eval_all_factors.py` 现在每写完一个面板就 `POSIX_FADV_DONTNEED`。

## 9. 你的任务:可交易性约束与持仓优化

### 9.1 要加的约束

1. **整百股**:每只股票的持股数是 100 的整数倍。需要价格 —— 立方体里有
   `day_last(Close)` 等日频字段(见 `daily.DAILY_FIELD_EXPRESSIONS`),
   **注意:Close 是后复权的,Amt/Volume 不是**(`docs/HANDOFF.md` §"永远不要用 Amt/Volume 当价格")。
   成交用次日开盘 15 分钟 VWAP 更合口径(标签就是它)。
2. **单票上限**:`w_i ≤ cap`,`cap` 要扫(建议 0.5% / 1% / 2% / 5% / 无上限)。
3. **组合总金额**:要指定一个资金规模(建议扫 1000 万 / 1 亿 / 10 亿),因为整百股
   约束的影响完全取决于资金量 —— 1000 万买 1000 只股票,每只平均 1 万元,
   一手 50 元的股票只能买 200 股,离散化误差很大。

### 9.2 目标函数

用户给的:`max Σ_i w_i · exp(MinMax(signal_i))`,其中 `w_i` 是**实际持仓金额占比**。
注意这是个线性目标(权重的线性函数),加上 `w_i ≤ cap`、`Σw_i ≤ 1`、整百股的整数约束,
是一个**带整数变量的线性规划**。

**我的建议**:先做两个版本对比,再决定要不要上真正的整数规划求解器。
- **贪心版**(先做这个):按 `exp(MinMax(signal))` 降序,逐只按 `min(cap, 剩余资金)`
  分配,向下取整到整百股,剩余资金继续往下分。O(n log n),每天几毫秒。
- **LP 松弛 + 取整**:先解连续解(其实就是"按分数贪心"),再向下取整,余额补给
  还没到 cap 的最高分股票。和贪心版大概率只差一点点。
- **真·整数规划**:除非前两个差距明显,否则不值得 —— 每天解一次 5220 变量的 MIP,
  回测 583 天会很慢。

### 9.3 评估口径(一定要和现有结果可比)

- 用 `_bench/champion_signal.npy` 当输入信号(也可以同时跑 `sig_OLS贪心67.npy`)。
- 平滑:半衰期在训练段选,现在冠军信号配的是 **hl=5**。
- 基准:等权全市场;报**超额**夏普/年化/回撤,同时报绝对口径。
- 成本:单边 15bp。换手要按**实际成交金额**算(整百股约束会让换手不等于权重变化)。
- **基线对照必须是"前20% · exp1 · hl5 → 超额夏普 +1.92"**,你的约束版要和它比,
  看可交易性约束吃掉多少。

### 9.5 还没做但很重要的(如果你有余力)
